知识地图：基础 → 进阶 → 前沿

方向 A · 图像/视频复原与增强

🟢 基础层（本科~研一）
  • 退化建模：大气散射模型（去雾）、模糊卷积核/运动核（去模糊）、加性高斯噪声与泊松分布（去噪）、Retinex 光照-反射分解（低照度）
  • 经典先验：暗通道先验、低秩先验、稀疏表示、全变差(TV)、BM3D 等传统正则化 → 对应 Enhanced Low-Rank Prior (TIP'16)
  • CNN 基础：卷积、池化、残差学习（残差连接与 ResNet）、多尺度特征、 转置卷积/上采样、patch 提取
  • 经典深度复原：SRCNN、DnCNN、MSCNN（去雾）、LLNet（低照度）、NAFNet 骨架
🟡 进阶层
  • 注意力机制：自注意力/通道注意力/空间注意力/窗口注意力 → 对 FocalNet / VIVNet
  • 频域视角：小波/DCT/低频与高频分解、频域选择调制 → FSNet / SFNet（TPAMI'24）
  • Transformer 复原：Restormer、SwinIR、NAFNet 的 token 化与全局建模
  • 多尺度与融合：多尺度可分离模块（UHD 视频去模糊）、Gated Fusion、跨尺度融合
  • 损失函数：L1/L2、感知损失(Perceptual)、对抗损失、SSIM 损失、Charbonnier 损失
  • 评估：PSNR、SSIM、LPIPS、NIQE（无参考）；常用数据集 NYU-Depth(合成去雾)、GoPro(去模糊)、SIDD(去噪)、LOL(低照度)、DIV2K(超分)
🔴 前沿层
  • 统一/通用复原：一个骨架处理去噪+去雾+去模糊+超分 → ConvIR、PoolNet、AdaIR、FocalNet
  • Mamba/状态空间模型：线性复杂度长程建模 → NDMamba、MatIR、FMambaIR
  • 扩散模型复原：以 Diffusion Transformer 完成盲恢复、内容先验注入 → Dual-Prompting (CVPR'25)
  • 盲复原与退化估计：同时估计退化核 + 复原内容；重度退化不匹配时如何自适应
  • 深度展开 / 先验指导：把迭代优化展开成网络（ISR）、3D 人脸先验指导人脸恢复

方向 B · 网络空间内容安全

🟢 基础层
  • 信号与频域：DFT/DCT、JPEG 压缩伪影、噪声统计，鉴别「图像经过处理」的痕迹
  • 二分类与表征学习：ReLU 分类头、交叉熵、欧氏空间的样本分布与过拟合
  • 数据清洗：FF++、Celeb-DF、DFDC 数据集构造与标签体系
  • 通用视觉骨干：CNN / ViT / CLIP 的视觉编码
🟡 进阶层
  • 特征解耦 / Disentanglement：把「内容」与「伪造痕迹」分离 → Multi-Scale Disentanglement (AAAI'25)
  • 鲁棒性与对抗：JPEG 重压缩、分辨率缩放后的检测稳定性；频域+空间互补特征
  • 决策驱动 / 正则约束：正交约束使压缩扰动不影响决策 → Decision-Driven Orthogonal Learning (AAAI'25)
  • 身份级 / 时序检测：视频帧间不一致、眨眼/心跳等生理信号线索
🔴 前沿层
  • AIGC 内容检测：检测扩散模型 / GPT-4o 等生成图与视频（DIRE、DiffusionRecon、OpenFake）
  • 多模态 LLM 检测：利用 VLM 语义推理鉴别伪造；多模态线索融合
  • 大模型安全 / 可信 AI：越狱提示、中毒攻击、模型鲁棒性与对齐
  • 联合建模：鲁棒水印 + 篡改定位（如 OmniGuard、GenPTW 思路）；被动与主动检测结合
💡 两条主线的最大交集 = 你的杠杆 「对退化与伪影的敏感」同时训练了复原（去伪影）与检测（辨伪影）两套能力。建议把频域分析、注意力机制、表征解耦三块作为必修硬核，它们是连接两方向的知识桥梁。

代码实例与工程上手

4.1 退化模型：科研的「造数据」起点

复原任务要先把干净图人为退化，才能有监督地训练。以下是最常用的几种退化合成（PyTorch）。

退化合成 · 去雾（大气散射模型）+ 去噪（加噪）+ 模糊（高斯核）
# 大气散射模型: I(x) = J(x)·t(x) + A·(1 - t(x)) t 为透射率, A 为大气光 import torch, torch.nn.as nn, torch.nn.functional as F def add_haze(clean, depth_map, A=0.7, beta=1.0): # t = exp(-beta * depth)，depth 来自深度图(如 NYU-Depth) t = torch.exp(-beta * depth_map).clamp(0.05, 1.0) hazy = clean * t.unsqueeze(1) + A * (1 - t).unsqueeze(1) return hazy def add_noise(img, sigma=25/255.0): return img + torch.randn_like(img) * sigma # 高斯噪声 def add_blur(img, kernel_size=11, sigma=2.0): grid = torch.arange(kernel_size, dtype=torch.float32) - kernel_size//2 x, y = torch.meshgrid(grid, grid, indexing='ij') ker = torch.exp(-(x**2+y**2)/(2*sigma**2)); ker /= ker.sum() ker = ker.view(1,1,kernel_size,kernel_size).repeat(3,1,1,1) return F.conv2d(img, ker, padding=kernel_size//2, groups=3)
✅ 为什么重要导师许多论文难点在「真实退化」：过于理想化的合成退化会让模型在真实照片失效。理解退化模型 = 理解任务本质，也方便复现《Benchmarking Dehazing》等基准。

4.2 最小可用复原网络：Residual 学习的 UNet 版「Mini ConvIR」

一个可训练、可扩展的复原主干（残差 + 编码解码）
import torch.nn.as nn class DoubleConv(nn.Module): def __init__(self, cin, cout): super().__init__() self.net = nn.Sequential( nn.Conv2d(cin, cout, 3, padding=1), nn.ReLU(inplace=True), nn.Conv2d(cout, cout, 3, padding=1), nn.ReLU(inplace=True)) def forward(self, x): return self.net(x) class MiniRestore(nn.Module): # 输入退化图，残差学习预测"干净的残差增量" -> output = input + residual def __init__(self, cin=3, base=32): super().__init__() self.enc1 = DoubleConv(cin, base) self.enc2 = DoubleConv(base, base*2) self.enc3 = DoubleConv(base*2, base*4) self.pool = nn.MaxPool2d(2) self.dec3 = DoubleConv(base*4, base*2) self.dec2 = DoubleConv(base*2, base) self.dec1 = DoubleConv(base, cin) def forward(self, x): e1, e2 = self.enc1(x), self.enc2(self.pool(self.enc1(x))) e3 = self.enc3(self.pool(self.enc2(self.pool(self.enc1(x))))) # 简化上采样跳过连接 d = F.interpolate(self.dec3(e3), scale_factor=2) + e2 d = self.dec2(d); d = F.interpolate(d, scale_factor=2) + e1 residual = self.dec1(d) return x + residual # 残差学习：直接学"改了哪里"
🧪 复现考核先分别用 add_haze / add_noise / add_blur 造数据训练此模型，比较三个任务的恢复效果差异——这能让你理解「不同退化需要不同归纳偏置」，也是读懂 FocalNet/ConvIR 改进点的基础。

4.3 训练与评估脚本（PSNR / SSIM）

PyTorch 最小训练循环 + 指标
import torch, torch.nn.as nn model = MiniRestore(); opt = torch.optim.Adam(model.parameters(), lr=1e-3) criterion = nn.SmoothL1Loss() # Charbonnier 简化版，复原任务常用 for epoch in range(30): for clean in train_loader: hazy = add_haze(clean, depth_map) # 在线合成 pred = model(hazy) loss = criterion(pred, clean) opt.zero_grad(); loss.backward(); opt.step() def psnr(pred, gt, maxv=1.0): mse = ((pred - gt) ** 2).mean() return 10 * torch.log10(maxv ** 2 / (mse + 1e-8)) def ssim(pred, gt): # 常用: pytorch_msssim 包 from pytorch_msssim import ssim return ssim(pred, gt, data_range=1.0)
⚠️ 常见坑PSNR 需在归一化一致（0–1 或 0–255）下比较；SSIM 与 LPIPS 更高层次语义更贴近人眼，论文一般同时上报三者。跑复现时先锁随机种子与数据划分，保证对比公平。

4.4 deepfake 检测骨架：解耦「内容 vs 伪造痕迹」的思路

表征解耦的最小示意（对应 AAAI'25 Multi-Scale Disentanglement 思想）
class DisentangleDetector(nn.Module): def __init__(self, backbone): super().__init__() self.backbone = backbone # CNN/ViT 特征提取 self.content_head = nn.Linear(512, 128) # 语义内容分支 self.forgery_head = nn.Linear(512, 128) # 伪造痕迹分支 self.cls = nn.Linear(128, 2) # 真/假分类 def forward(self, x): f = self.backbone(x) # [B,512] zc = self.content_head(f) # 内容表征 zf = self.forgery_head(f) # 伪造表征（核心判别线索） # 关键遗忘 / 解耦: 让 zc 不携带伪造信息，只用 zf 做判别 return self.cls(zf) # 训练时的解耦正则（示意）：正交损失迫使两分支不相关 def orthogonality(zc, zf): zc = F.normalize(zc, dim=-1); zf = F.normalize(zf, dim=-1) return (zc * zf).sum(dim=-1).abs().mean()

4.5 高频加分项：频域特征（两方向通用利器）

用 DCT / 小波提取低频与高频，辅助复原与检测
import torch, torch.fft # 将图像拆为低频(L)与高频(H) → 复原保留结构、检测关注伪影 freq = torch.fft.rfft2(img) low = torch.fft.irfft2(freq * mask_low) # mask_low 中心低频部分 high = img - low # 高频 = 细节/噪声/伪造痕迹 # 导师 FSNet 的核心思路即"频域选择调制"：对不同频段赋予不同权重

4.6 本地环境建议

  • 框架：PyTorch ≥ 1.9（导师多数仓库基于 PyTorch；Mamba 仓库需额外装 selective_scan / SSM 依赖）
  • 数据：先下载小规模子集（GoPro 去模糊、NYU 深度去雾、LOL 低照度）练手，避免一上来拖整库
  • 追踪：用 WandB / TensorBoard 记录 loss 与 PSNR 曲线，养成实验记录习惯
  • Diffusion/Mamba：涉及大模型时优先用 3090/4090 级别单卡或云端按需算力，先跑通推理
